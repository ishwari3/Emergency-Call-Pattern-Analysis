# Emergency Call Pattern Analysis

## Project Overview
This project focuses on analyzing 911 emergency call data to identify patterns, trends, and insights related to public safety and emergency response activities. The analysis is performed using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

## Objectives
- Analyze emergency call patterns
- Identify the most common emergency categories
- Examine call distribution across locations and time
- Visualize trends using graphs and heatmaps

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
The dataset contains 911 emergency call records including:
- Latitude and Longitude
- Emergency Title
- Timestamp
- Township
- Address
- Zipcode

## Key Analysis Performed
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Time-Based Analysis
- Heatmap Visualization
- Emergency Category Analysis

## How to Run the Project
1. Clone the repository
2. Install the required libraries using requirements.txt
3. Open the Jupyter Notebook
4. Run the notebook cells sequentially
